NETWORK BREACH DETECTED

A computer on the network has been hacked. You've been called in as the Cybersecurity Incident Responder. Follow the 5 steps of incident response to secure the system and save the data!

How to Play

1
DETECT — Find the infected computer. Look for subtle warning signs!
2
ISOLATE — Disconnect the infected computer from the network before the threat spreads.
3
BLOCK — Click suspicious data packets to block them. Don't block safe traffic!
4
ANALYZE — Search through system logs to find the attack source. Read carefully!
5
RECOVER — Restore files from backups in the correct order (oldest first).
